# 🐍 بازی مار

یک بازی Snake ساده و کامل با HTML/CSS/JavaScript، آماده برای GitHub Pages.

## اجرا
فایل `index.html` را باز کنید.

## انتشار در GitHub Pages
1. یک Repository جدید در GitHub بسازید.
2. سه فایل `index.html`، `style.css` و `script.js` را داخل Repository قرار دهید.
3. از مسیر Settings → Pages، گزینه Deploy from branch را انتخاب کنید.
4. Branch را روی `main` و پوشه را روی `/root` قرار دهید.
5. ذخیره کنید تا لینک بازی ساخته شود.

## کنترل
- کیبورد: کلیدهای جهت‌دار یا W A S D
- موبایل: دکمه‌های روی صفحه
- Space: توقف/ادامه
